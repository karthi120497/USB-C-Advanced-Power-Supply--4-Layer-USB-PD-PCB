**♦USB-C Advanced Power Supply – 4-Layer USB PD PCB♦**

**♦Project Overview**

Designed a 4-layer USB-C Power Delivery (USB PD) power supply PCB
supporting selectable output voltages of 5V, 9V, 12V, 20V and 28V.

The design uses a USB-C connector and USB PD controller for power
negotiation and output-voltage selection.

The board also includes configuration switches, voltage-status LEDs,
error indication, auxiliary 3.3V power supply, I2C header,
filtering and protection circuitry.

**♦Key Features**

- 4-layer PCB design
- USB Type-C Power Delivery
- Selectable 5V / 9V / 12V / 20V / 28V output
- USB PD controller
- CFG1 / CFG2 / CFG3 configuration switches
- Voltage indication LEDs
- Error LED indication
- +3.3V auxiliary power supply
- Input/output filtering
- Protection circuitry
- I2C header
- Mounting holes
- DRC verification
- Gerber generation
